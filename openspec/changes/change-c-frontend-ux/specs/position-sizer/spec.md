## ADDED Requirements

### Requirement: 使用者可計算建議部位規模
系統 SHALL 在 `/portfolio` 頁面提供「部位規模計算器」區塊（純前端計算）。輸入欄位：總資金（元）、單筆風險比例（%，預設 2%）、股價（元）、停損距離（元，即股價 - 停損價）。輸出：建議張數、最大投入金額、帳戶風險金額。

#### Scenario: 計算建議張數
- **WHEN** 使用者輸入總資金 1,000,000、風險比例 2%、股價 500、停損距離 12.5
- **THEN** 系統即時顯示：帳戶風險金額 20,000 元、建議張數 floor(20,000 / 12,500) = 1 張、最大投入金額 500,000 元

#### Scenario: 即時重新計算
- **WHEN** 使用者修改任一輸入欄位
- **THEN** 系統於輸入變更後 100ms 內更新所有輸出數值，不需點擊按鈕

#### Scenario: 輸入非法值
- **WHEN** 使用者輸入停損距離為 0 或負數
- **THEN** 系統顯示欄位驗證錯誤「停損距離必須大於 0」，輸出欄位清空

### Requirement: 系統顯示風險等級警示
系統 SHALL 依建議張數所代表的實際資金比例，顯示風險等級（低 / 中 / 高），若投入比例 > 50% 顯示橘色警示。

#### Scenario: 高風險警示
- **WHEN** 計算結果顯示最大投入金額佔總資金超過 50%
- **THEN** 系統在結果卡片顯示橘色「高集中度警示」標籤

#### Scenario: 正常風險範圍
- **WHEN** 最大投入金額佔總資金 20% 以下
- **THEN** 系統顯示綠色「風險適中」標籤
