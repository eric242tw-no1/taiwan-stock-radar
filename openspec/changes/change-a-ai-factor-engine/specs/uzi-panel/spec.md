## ADDED Requirements

### Requirement: UZI 評審團多派系評分

系統 SHALL 實作 UZI 評審團，由三位具名虛擬評審（動能派、價值派、風控派）各自對股票評分，最終加權合成總評分。

評審配置：
- **動能派**（權重 35%）：著重技術指標動能、價格突破、成交量
- **價值派**（權重 35%）：著重基本面估值、股息、財務健全度
- **風控派**（權重 30%）：著重波動度、下行風險、流動性

#### Scenario: 三位評審各自給分

- **WHEN** 呼叫 UZI 評審團分析 `symbol`
- **THEN** 系統透過 Claude API 為每位評審生成分析，各自輸出 0-100 分與評分理由（至少 2 句話）

#### Scenario: 加權合成最終評分

- **WHEN** 三位評審評分完成
- **THEN** 系統計算加權總分（動能 × 0.35 + 價值 × 0.35 + 風控 × 0.30），回傳 `UZIPanelResult`，包含各評審分數、理由與最終加權分

#### Scenario: 最終評分對應建議等級

- **WHEN** 加權總分計算完成
- **THEN** 系統依據分數區間輸出建議等級：≥75 為「強力買進」，60-74 為「買進」，40-59 為「觀望」，25-39 為「賣出」，< 25 為「強力賣出」
