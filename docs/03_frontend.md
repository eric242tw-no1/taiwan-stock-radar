## 第一頁：市場總覽（三列佈局）

### 第一列：台股市場
```
[市場溫度計 + 廣度]  [台股產業熱力圖12格]  [產業輪動 + 八大官股]
```

市場溫度計指標：
- 溫度值 0-100
- 上漲/下跌/漲停/跌停家數
- 成交金額、創60日新高家數、外資動向

台股熱力圖產業：半導體、AI伺服器、電動車、IC設計、面板、封測、PCB、網通、金融、傳產、航運、生技

### 第二列：美股市場
```
[美股四卡片]  [美股科技熱力圖9格]  [台美連動分析]
```

美股四大卡片：S&P500、Nasdaq 100、道瓊、**VIX 恐慌指數（獨立卡片）**
- VIX < 20 → 綠色（低恐慌，多頭有利）
- VIX 20–30 → 黃色（中度波動，謹慎）
- VIX > 30 → 紅色（高恐慌，注意風險）
- 資料來源：yfinance `^VIX`，每5分鐘更新
輔助指標：費城半導體、DXY（小字輔助）
科技熱力圖（藍色系）：NVDA、AMD、TSMC ADR、MSFT、AVGO、GOOGL、ASML、AMAT、META

台美連動：NVDA/費半/TSMC ADR 對台股相關係數（來自 macro_correlation 表）

### 第三列：個股動向
```
[波段領頭羊]  [個股排行榜]  [市場快訊]
```

波段領頭羊：創60日高 / 鎖漲停 切換
排行榜：漲幅 / 跌幅 / 成交量 切換
快訊：AI 摘要，底部有「AI 深度總覽」按鈕

## 第二頁：個股分析（兩欄佈局）

### 左側：分析記錄欄（可收合）
```
📋 分析記錄
─────────────
■ 2330 台積電  持有 87分  06/04 15:30
□ 2454 聯發科  觀望 62分  06/04 14:20
□ 2317 鴻海    減倉 41分  06/03 16:10
```

評分顏色：≥80 綠色、50-79 黃色、<50 紅色

### 主內容區

**頂部**：股票名稱、現價、漲跌幅、時間軸切換（1D/5D/1M/3M）

**重要事件倒數面板**（橫排三格）：
- 法說會倒數（≤3天 紅色警示）
- 除息日倒數（≤5天 黃色警示）
- 台指期結算倒數（≤5天 橘色警示）⚠️

**左欄（寬）**：
- K 線圖（TradingView Widget）
- 成交量
- 技術指標六格：RSI / MACD / KD / 布林通道 / VWAP / MA排列

**右欄（窄）**：
- AI 決策中心（評分環形圖 + 建議 + 正面/風險因素）
- TradingView 信號模組（AI 替代 / Webhook 切換）

**底部三欄**：
- 籌碼分析（三大法人 + 融資融券 + 借券 + 券商分點Top5 + 集中度）
- 衍生商品（外資期貨淨部位 + PCR + 未平倉 + 選擇權支撐壓力）
- 乖離率分析（MA20偏離% + 歷史百分位 + 過熱判斷 + MA5/20/60）

## 第三頁：選股工作流

**策略選擇器**：
```
● 波段技術分析  ○ 事件驅動  ○ 趨勢跟隨  ○ 配對對沖（Phase 3）
```

**因子掃描結果**（每日自動更新）：
- 全市場 1,800+ 檔 → 篩選後候選清單 20-30 檔
- 顯示各因子通過狀況 + 綜合評分排序

**自選股池（8-10檔）**：
- 手動加入/移除
- 每日 AI 報告摘要
- 每檔顯示：AI評分 + 操作建議 + 狙擊點位

**每日 AI 報告格式**：
```
操作建議 + 評分
理想買入價 / 次優買入價
止損價 / 止盈目標
今日重點（✅/⚠️/❌）
```

---

## 第四頁：持倉追蹤

- 持倉清單（股票、成本、現價、損益%）
- 總資產 / 現金 / 持股市值
- 當日損益 / 累計損益
- 個別持股損益走勢圖

---

## 第五頁：回測

**輸入區**：
- 選擇股票
- 回測期間
- 進場條件（多選）
- 出場條件（停利% / 停損% / 持有天數）

**輸出報告**：
- 總報酬率、勝率、最大回撤
- 夏普比率、平均持有天數
- 逐筆交易明細
