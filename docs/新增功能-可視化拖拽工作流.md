# 新增功能：可視化拖拽工作流

> **文件狀態**：規劃中
> **目標系統**：Taiwan AI Stock Radar
> **建議整合階段**：Phase 2（回測模組完成後）
> **預估工程量**：前端 3–5 天 / 後端 API 2–3 天

---

## 一、功能概述

在 Taiwan AI Stock Radar Dashboard 內嵌一個可視化拖拽工作流編輯器，讓使用者透過圖形化節點設計 AI Agent 執行流程與因子計算鏈，無需直接修改程式碼即可調整策略邏輯。

靈感來源：[PandaAI QuantFlow](https://github.com/PandaAI-Tech/panda_quantflow) 的節點式工作流設計，結合台股雷達既有的 6-Agent 決策引擎架構。

---

## 二、使用情境

| 情境 | 說明 |
|------|------|
| 策略快速調整 | 不改後端程式，直接在畫布上增減 Agent、調整執行順序 |
| 因子組合實驗 | 拖拽 RANK / DELAY / STDDEV 等因子節點，快速組合新策略 |
| 流程視覺化確認 | 執行前一眼看清整條 Agent 鏈，避免邏輯錯誤 |
| JSON 導入導出 | 策略流程可存檔、分享、版本管理 |

## 三、節點類型定義

### 3.1 資料層節點（藍色）

```
DataSourceNode
├── 資料源：FinMind / twstock / yfinance
├── 股票代號（單一 or 批量）
├── 時間範圍（起訖日期）
└── 資料頻率（日線 / 週線）
```

### 3.2 因子層節點（紫色）

```
FactorNode
├── RANK(expr, N)        — N日排名百分位
├── DELAY(expr, N)       — N日前數值
├── STDDEV(expr, N)      — N日標準差
├── CORRELATION(x, y, N) — N日相關係數
├── MA(expr, N)          — 移動平均
└── 自訂公式（Python 運算式輸入）
```

### 3.3 Agent 層節點（綠色）

對應台股雷達現有 6 個 AI Agent：

```
AgentNode
├── TrendAgent    — 趨勢判斷
├── MomentumAgent — 動能分析
├── VolumeAgent   — 成交量分析
├── PatternAgent  — 型態識別
├── ChipAgent     — 籌碼分析
└── RiskAgent     — 風控評估
```

### 3.4 邏輯層節點（橘色）

```
FilterNode
├── 條件閾值（例：RSI > 50）
├── AND / OR 邏輯組合
└── 排序取前 N 檔
```

### 3.5 輸出層節點（紅色）

```
OutputNode
├── SignalNode  — 產生買進 / 賣出 / 觀望訊號
└── NotifyNode  — 觸發 Telegram 推播通知
```

## 四、技術選型

### 前端：React Flow

```bash
npm install @xyflow/react
```

**選用理由：**
- 業界標準 React 拖拽工作流庫（GitHub 21k+ stars）
- 原生支援：自訂節點外觀、貝茲連線、縮放平移、JSON 匯入匯出、撤銷重做
- 與 Next.js 15 完全相容
- 僅需定義各節點 React 元件外觀，連線邏輯由 React Flow 負責

### 後端：FastAPI 工作流執行 API

新增一個執行端點，接受 JSON 工作流定義並驅動 Agent 鏈：

```
POST /api/workflow/run
Body: WorkflowSchema（見第五節）
Response: 即時 SSE 串流執行狀態
```

## 八、執行引擎邏輯（後端 Python 虛擬碼）

```python
class WorkflowRunner:
    def __init__(self, workflow: WorkflowSchema):
        self.nodes = {n.id: n for n in workflow.nodes}
        self.edges = workflow.edges

    def topo_sort(self) -> list[str]:
        """拓撲排序，決定節點執行順序"""
        in_degree = {n: 0 for n in self.nodes}
        adj = {n: [] for n in self.nodes}
        for e in self.edges:
            adj[e.source].append(e.target)
            in_degree[e.target] += 1
        queue = [n for n, d in in_degree.items() if d == 0]
        result = []
        while queue:
            node = queue.pop(0)
            result.append(node)
            for neighbor in adj[node]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        return result

    async def run(self) -> AsyncGenerator[dict, None]:
        """依拓撲順序逐節點執行，SSE 回傳進度"""
        order = self.topo_sort()
        context = {}
        for node_id in order:
            node = self.nodes[node_id]
            yield {"event": "node_start", "node_id": node_id}
            result = await self.execute_node(node, context)
            context[node_id] = result
            yield {"event": "node_done", "node_id": node_id, "result": result}

    async def execute_node(self, node, context):
        if node.type == "DataSourceNode":
            return await fetch_market_data(node.config)
        elif node.type == "FactorNode":
            return await calc_factor(node.config, context)
        elif node.type == "AgentNode":
            return await run_agent(node.config.agent, context)
        elif node.type == "SignalNode":
            return await generate_signal(context)
        elif node.type == "NotifyNode":
            return await send_telegram(context)
```
