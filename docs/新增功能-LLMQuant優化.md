### A01｜Sector Rotation Agent（類股輪動偵測）
**優先度：** ⭐⭐⭐  
**開發階段：** Phase 2

**說明**  
自動識別資金在哪個族群流動（半導體 → 金融 → 傳產 → 生技…），幫助波段投資者跟對主流族群，避免買到輪動末段的個股。

**邏輯設計**
```
輸入：各族群 ETF 近 5/10/20 日漲幅 + 成交量
輸出：
  - 強勢族群 Top 3（加碼方向）
  - 弱勢族群 Bottom 3（迴避）
  - 輪動階段判斷（初升 / 主升 / 末升 / 回檔）
```

**追蹤標的（ETF 代理）**
- 0050（大盤）、0052（科技）、00733（電子）
- 00850（金融）、00701（傳產）、00736（生技）

## 四、🎯 風控與倉位管理

### R01｜動態停損計算器（ATR-based）
**優先度：** ⭐⭐⭐  
**開發階段：** Phase 1（Sprint 2）

**說明**  
根據個股波動度（ATR）自動計算合理停損價，避免停損設太緊被震出或太鬆虧損擴大。

**計算公式**
```
停損價 = 進場價 - (ATR × 倍數)
建議倍數：
  - 短線波段（5–10 日）：1.5x ATR
  - 中線波段（20–60 日）：2.5x ATR
```

**Dashboard 呈現**：個股分析頁右側面板，即時顯示建議停損價與停損幅度 %

---

### R02｜部位規模計算器
**優先度：** ⭐⭐⭐  
**開發階段：** Phase 1（Sprint 2）

**說明**  
根據帳戶總資金、每筆最大虧損金額、停損幅度，自動計算建議下單張數。

**計算邏輯（Fixed Fractional）**
```
每筆最大虧損 = 總資金 × 風險比例（建議 1–2%）
建議張數 = 每筆最大虧損 ÷ (停損幅度 × 每張面額)
```

**可選模式**
- Fixed Fractional（固定風險比例）— 預設
- Kelly Criterion（凱利公式）— 進階模式，需輸入勝率與賠率

---

### R03｜投資組合熱力圖
**優先度：** ⭐⭐  
**開發階段：** Phase 3

**說明**  
計算持倉標的之間的相關性矩陣，以熱力圖呈現。高相關持倉 = 集中風險，提示分散化建議。

**技術實作**：`pandas.DataFrame.corr()` + Recharts Heatmap

---

### R04｜最大回撤即時警報
**優先度：** ⭐⭐⭐  
**開發階段：** Phase 1（Sprint 2）

**說明**  
帳戶淨值若從高點回撤超過設定閾值（預設 10%），立即推播 Telegram 警告，觸發強制檢視機制。

**警報等級**
| 回撤幅度 | 警報等級 | 建議行動 |
|---------|---------|---------|
| 5% | 🟡 注意 | 檢視持倉 |
| 10% | 🟠 警告 | 減碼 50% |
| 15% | 🔴 危險 | 全部出場 |
